### 5. 问题排查

#### 如果看到错误日志：

```
❌ "LifecycleManager 初始化失败"
```

**原因**: LifecycleManager 初始化异常  
**影响**: 低 - 应用仍能正常运行，只是没有生命周期管理  
**处理**: 查看详细错误信息，可能是依赖模块未正确初始化

---

#### 如果看到错误日志：

```
❌ "LifecycleManager 注册页面失败"
```

**原因**: 页面注册时机不对  
**影响**: 低 - 页面功能正常，只是没有生命周期管理  
**处理**: 检查 LifecycleManager 是否已初始化

---

#### 如果应用崩溃：

**立即回退步骤**:

1. 打开 `EntryAbility.ets`
2. 将 `ENABLE_LIFECYCLE_MANAGER` 改为 `false`
3. 打开 `Index.ets`
4. 将 `ENABLE_LIFECYCLE_MANAGER` 改为 `false`
5. 重新编译运行
