### 2.2 声音特质定义

#### 🎯 **基础音色**
```
【音色类型】元气澄澈少女声

【声音质感】
- 清澈透亮：如星空般澄澈，不浑浊
- 明亮活泼：如阳光般温暖，有活力
- 圆润自然：不过于尖锐，自然舒适

【音域定位】
- 基频范围：220-280Hz（女性高音区）
- 适合音域：A3（220Hz）～ E5（659Hz）
- 最适说话音域：A3 - C5

【声音温度】
- 整体偏暖：不是冰冷的甜美
- 带轻微气息感：模拟自然呼吸
- 亲和力强：如朋友般的温暖
```

#### 🎵 **说话风格**
```
【语速】中等偏快
- 基础语速：正常语速的1.05-1.1倍
- 目的：展现元气活力
- 注意：不过快，保持清晰

【节奏】
- 轻快跳跃：像音符般有节奏感
- 句子间适度停顿：自然的呼吸感
- 重点词加重：突出关键信息

【语调】
- 基础语调：偏高（+5-10%音调）
- 句尾上扬：2-5度的自然上扬
- 疑问句：明显上扬5-10度
- 感叹句：音调升高+音量加强

【停顿】
- 句中停顿：自然换气
- 句末停顿：完整的呼吸周期
- 强调停顿：用于突出重点
```

#### 💫 **情感表达**

| 情感状态 | 音高变化 | 语速变化 | 音量变化 | 音色特点 |
|---------|---------|---------|---------|----------|
| **开心** | +15-20% | +15-20% | +10-15% | 明亮跳跃，像小鸟般欢快 |
| **温柔** | -5% | -15% | -20% | 轻柔细腻，像微风般舒适 |
| **元气** | +10-15% | +10-15% | +10-15% | 明亮有力，充满能量 |
| **撒娇** | +5-10% | -5% | -15% | 尾音延长，鼻音增加 |
| **鼓励** | +10-15% | +10% | +15-20% | 坚定有力，温暖有力 |
| **疑惑** | +5% | +5% | -5% | 略带停顿，像在思考 |
| **惊喜** | +20-25% | +20-25% | +15-20% | 突然升高，充满活力 |
| **害羞** | +5% | -10% | -15% | 音量降低，语速放缓 |

### 3.2 中文语调优化

#### 声调特征（普通话）
```
【一声】阴平：高平调，55
  → 爱莉风格：保持高平，但末尾轻微上扬

【二声】阳平：中升调，35
  → 爱莉风格：上扬更明显，增加活力感

【三声】上声：降升调，214
  → 爱莉风格：降的部分稍短，升的部分延长

【四声】去声：全降调，51
  → 爱莉风格：降调保持干脆，但不完全压抑
```

#### 语气词设计
```
【常用语气词】
- 中文："呀"、"呢"、"哦"、"嘛"、"呀～"
- 日语："～"、"☆"、"って感じ"、"かな～"
- 组合：中文基础 + 日语点缀

【语调特点】
- 句尾上扬：非疑问句也轻微上扬
- 感叹句：明显夸张的上扬
- 停顿：用"～"或"…"增加节奏感
```

```
【日语元音】比中文更清晰、更长
```

### 4.2 中日混说策略

```typescript
// 根据语言类型选择TTS策略
async speak(text: string, emotion: string = 'happy') {
  const containsJapanese = /[\u3040-\u309F\u30A0-\u30FF]/.test(text);
  
  if (containsJapanese) {
    // 分割日语和中文部分
    const parts = this.splitByLanguage(text);
    
    for (const part of parts) {
      if (part.isJapanese) {
        // 日语部分：使用罗马音 + 英文模式
        const romanji = this.toRomanji(part.text);
        await this.tts.speak(romanji, {
          language: 'en-US',
          ...this.getEmotionParams('energetic')
        });
      } else {
        // 中文部分：使用中文模式
        await this.tts.speak(part.text, {
          language: 'zh-CN',
          ...this.getEmotionParams(emotion)
        });
      }
      
      // 适当停顿分隔
      await this.delay(200);
    }
  } else {
    // 纯中文：直接播报
    await this.tts.speak(text, {
      language: 'zh-CN',
      ...this.getEmotionParams(emotion)
    });
  }
}
```

### 6.2 声音管理器实现

```typescript
// AiriVoiceManager.ts - 爱莉专属声音管理器

export class AiriVoiceManager {
  // 声音配置
  private static readonly BASE_CONFIG = {
    language: 'zh-CN',
    person: 0,
    speed: 1.08,
    pitch: 1.08,
    volume: 1.55
  };
  
  // 情感参数映射
  private static readonly EMOTION_MAP = {
    happy:      { speed: 1.20, pitch: 1.18, volume: 1.65 },
    gentle:     { speed: 0.92, pitch: 1.03, volume: 1.35 },
    energetic:  { speed: 1.15, pitch: 1.15, volume: 1.60 },
    coquettish: { speed: 1.05, pitch: 1.12, volume: 1.40 },
    encouraging:{ speed: 1.12, pitch: 1.12, volume: 1.60 }
  };
  
  // 获取情感参数
  static getEmotionParams(emotion: string) {
    return this.EMOTION_MAP[emotion] || this.BASE_CONFIG;
  }
  
  // 智能文本处理
  static async speak(text: string, emotion: string = 'happy') {
    // 检测语言
    const hasJapanese = /[\u3040-\u309F\u30A0-\u30FF]/.test(text);
    
    // 获取情感参数
    const params = this.getEmotionParams(emotion);
    
    // 日语处理
    if (hasJapanese) {
      // 混合播报逻辑
      await this.speakMixed(text, params);
    } else {
      // 中文直接播报
      await TextToSpeechManager.speak(text, {
        ...params,
        language: 'zh-CN'
      });
    }
  }
  
  // 混合语言播报
  private static async speakMixed(text: string, params: any) {
    const parts = this.splitByLanguage(text);
    
    for (const part of parts) {
      if (part.isJapanese) {
        // 日语转罗马音播报
        const romanji = this.toRomanji(part.text);
        await TextToSpeechManager.speak(romanji, {
          ...params,
          language: 'en-US'
        });
      } else {
        await TextToSpeechManager.speak(part.text, {
          ...params,
          language: 'zh-CN'
        });
      }
      await this.delay(150);
    }
  }
}
```

| **鼓励用户** | "加油加油！你一定可以的！星空在为你闪耀哦～⭐" | encouraging, speed: 1.12 | 坚定有力，温暖有力 |
| **撒娇** | "呜～不要走嘛，再陪我聊一会儿嘛～" | coquettish, speed: 1.05 | 软萌可爱，尾音延长 |
| **惊喜** | "哇～真的吗！太棒了呀！！" | surprised, speed: 1.25 | 突然兴奋，音调升高 |

| **害羞** | "那个…其实我也有点紧张呢…" | shy, speed: 0.90 | 轻柔降低，音量减小 |

## 八、声音一致性标准

### 8.1 质量检查清单

#### ✅ 必须做到
- [ ] 音色保持清澈透亮，不过于尖锐
- [ ] 语速适中偏快，展现元气感
- [ ] 句尾语调自然上扬
- [ ] 换气停顿自然，不生硬
- [ ] 情感表达与场景匹配
- [ ] 日语发音清晰准确

#### ❌ 避免出现
- [ ] 音色过于低沉或浑浊
- [ ] 语速过慢，显得拖沓
- [ ] 语调平直无起伏
- [ ] 机械化的停顿
- [ ] 情感表达不自然
- [ ] 日语发音错误

### 8.2 声音审核标准

| 维度 | 优秀 | 合格 | 不合格 |
|------|------|------|--------|
| **清晰度** | 咬字清晰，无含糊 | 基本清晰 | 有含糊或错误 |
| **自然度** | 像真人自然对话 | 基本自然 | 明显机械感 |
| **情感度** | 情感丰富恰当 | 基本有情感 | 无情感表达 |
| **特色度** | 明显爱莉风格 | 有一定特色 | 无辨识度 |
| **连贯度** | 停顿自然流畅 | 基本连贯 | 生硬不连贯 |
