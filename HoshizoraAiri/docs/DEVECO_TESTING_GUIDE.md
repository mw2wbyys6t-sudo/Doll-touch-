## 🚀 测试前准备

### 1. 打开项目

在 DevEco Studio 中：
```
File → Open → 选择 /workspace/ohos_airi 目录
```

### 2. 同步项目

等待项目自动同步完成，或手动触发：
```
File → Sync Project with Gradle Files
```

### 3. 检查编译错误

查看 **Build** 窗口：
- ✅ 应该显示 "BUILD SUCCESSFUL"
- ❌ 如果有错误，请立即停止并报告

## 📋 测试步骤

### 步骤 1: 编译项目

#### 方法 1: 使用菜单
```
Build → Build Hap(s) / APP(s) → Build Hap(s)
```

#### 方法 2: 使用快捷键
```
Ctrl + F9 (Windows/Linux)
Cmd + F9 (Mac)
```

#### 方法 3: 使用 Gradle
在 **Terminal** 中执行：
```bash
npm run build
```

**期望结果**:
```
✅ BUILD SUCCESSFUL
✅ 无 TypeScript 错误
✅ 无编译警告
```

**如果失败**:
1. 查看 **Build** 窗口的错误信息
2. 截图保存错误日志
3. 报告错误详情

---

### 步骤 2: 配置运行目标

#### 选择模拟器或真机

1. **使用模拟器**:
   ```
   Tools → Device Manager
   → 选择一个模拟器（推荐：HarmonyOS NEXT 模拟器）
   → 点击启动按钮
   ```

2. **使用真机**:
   ```
   连接真机到电脑
   → 启用开发者模式
   → 允许 USB 调试
   → 在 DevEco 中选择真机
   ```

**推荐配置**:
- 设备类型：Phone
- HarmonyOS 版本：NEXT
- 屏幕分辨率：1080x2340

---

### 步骤 3: 运行应用

#### 方法 1: 点击运行按钮

点击工具栏的绿色 ▶ 按钮

#### 方法 2: 使用快捷键
```
Shift + F10 (Windows/Linux)
Ctrl + R (Mac)
```

#### 方法 3: 使用 Gradle
在 **Terminal** 中执行：
```bash
npm run start
```

**期望结果**:
- 应用成功安装到设备
- 应用自动启动
- 显示 Index 页面

## 🚨 紧急情况处理

### 如果应用崩溃

**处理步骤**:
1. 记录崩溃时的操作
2. 查看崩溃日志（HiLog 中的 Error 级别）
3. 截图保存
4. 回退代码（将 ENABLE_LIFECYCLE_MANAGER 改为 false）
5. 重新测试

### 如果内存泄漏严重

**处理步骤**:
1. 截图保存内存曲线
2. 查看是否有定时器未清理
3. 检查日志中是否有清理信息
4. 回退代码
5. 报告问题

### 如果功能异常

**处理步骤**:
1. 记录异常现象
2. 查看相关日志
3. 截图保存
4. 回退代码
5. 报告问题
